# Earthymic Herbs — Local Demo Store

## Run locally
1. Keep the folder structure unchanged.
2. Open `index.html` in Chrome/Edge/Firefox.
3. No server or installation is required for this demo.

## What is included
- Earthymic logo
- Herbs-only storefront
- Original Earthymic-style packaging mockups (not copied from another store)
- Amla, Rosemary, Multani Mitti, Bhringraj, Shikakai, Reetha, Ashwagandha and Hibiscus
- Search and sorting
- Cart
- Enquiry form demo
- Responsive mobile layout

## Before public launch
Connect the enquiry form to your preferred email/WhatsApp/backend, replace demo product descriptions/prices, add real product photography, and add the required legal/product information for the products you actually sell.
